# UChicago MPP — Coursework

Academic coursework repository for the Master of Public Policy program at the University of Chicago Harris School of Public Policy (2025-2027).

## Structure

```
uchicago-mpp/
├── 1_autumn_2025/
│   ├── codinglab/        # R programming — final project
│   ├── micro1/           # Microeconomics I — problem sets & writing
│   └── stats1/           # Statistics I — problem sets
│
├── 2_winter_2026/
│   ├── analytical-politics2/   # Analytical Politics II — lectures
│   ├── micro2/                 # Microeconomics II — problem sets
│   ├── stats2/                 # Statistics II — problem sets
│   └── _workshops/             # ggmap and spatial visualization
│
└── 3_spring_2026/
    ├── AI_xlab/            # AI Policy Lab — policy memo (EN/ES)
    ├── corporate-finance/  # Corporate Finance — problem sets & study guide
    ├── data_programming/   # Data Programming in Python — skill & applied psets
    └── program-evaluation/ # Program Evaluation — problem sets
```

## Tools & Languages

- **R** — econometrics, statistics, spatial analysis (ggmap), R Markdown
- **Python** — data programming (pandas, matplotlib)
- **Quarto (.qmd)** — problem sets and policy documents rendered to PDF/HTML
- **LaTeX** — typesetting via Quarto/Pandoc
